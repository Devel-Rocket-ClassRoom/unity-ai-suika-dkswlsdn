# 🍉 수박게임 (Suika Game) — Game Design Document

**버전** 1.0 | **개발사** Aladdin X | **출시** 2021(JP) · 2023(글로벌) | **플랫폼** Nintendo Switch · iOS · Browser

---

## 1. 게임 개요

### 한 줄 요약

> 박스 안에 과일을 떨어뜨려 같은 과일끼리 합치고, 체리에서 수박까지 진화시키며 최고 점수를 노리는 물리 기반 머지 퍼즐.

### 기본 정보

| 항목 | 내용 |
|------|------|
| 장르 | 퍼즐 / 머지 / 물리 기반 캐주얼 |
| 플레이어 | 싱글플레이어 (2024년 DLC로 로컬 2인 대전 추가) |
| 시간 제한 | 없음 |
| 과일 종류 | 11종 |
| 낙하 가능 과일 | 하위 5종 (체리 ~ 감) |
| 다음 과일 예고 | 1개 선공개 |
| 원작 | 중국 브라우저 게임 '합성대서과(合成大西瓜)' (2021.01) |

### 코어 루프

```
① 다음 과일 예고 확인
        ↓
② X 위치 결정 후 낙하
        ↓
③ 물리 충돌 · 안착
        ↓
④ 동일 과일 접촉 → 머지
        ↓
⑤ 점수 획득 · 공간 확보
        ↓
    ① 반복 (박스 오버플로우 시 게임오버)
```

## 2. 핵심 메커닉

### 2-1. 떨어뜨리기 (Drop)

- 플레이어는 화면 상단에서 좌우로 이동하며 원하는 **X 좌표를 선택**한 뒤 과일을 낙하시킨다.
- 마우스 클릭 또는 터치로 위치 결정, 낙하 중 방향 변경 불가.
- 낙하 순서는 **완전 랜덤**이지만, 다음 과일 1개를 미리 확인할 수 있다.
- 낙하 가능한 과일은 **1~5단계(체리 ~ 감)** 로 제한된다.

### 2-2. 물리 충돌 (Physics)

- 2D 리지드바디 물리 엔진 적용. 모든 과일은 **원형 콜라이더(Circle Collider)**.
- 과일마다 고유한 **무게와 탄성**이 있어 튀거나 굴러가는 방식이 다르다.
- 머지 발생 시 에너지가 방출되어 **주변 과일이 밀릴** 수 있으며, 이로 인해 의도치 않은 게임오버가 발생하기도 한다.
- Tetris와 달리 중력·관성이 존재하기 때문에 예측 난이도가 높다.
- Nintendo Life 리뷰 표현: *"물리 엔진이 붙은 2048"*

### 2-3. 머지 (Merge)

- 같은 종류의 과일 2개가 **접촉하면 즉시 합쳐져** 다음 단계 과일 1개로 변환된다.
- 새 과일은 **두 과일의 중심 위치**에 생성된다.
- **연쇄(체인) 머지** 가능 — 한 번의 낙하로 여러 단계 연속 머지 시 점수 폭발적 증가.
- 수박(11단계) 2개가 머지되면 **박스에서 소멸**, 공간 확보 + 보너스 점수 획득.

### 2-4. 게임오버 (Game Over)

- 어느 과일이든 박스 **상단 기준선(빨간 선)을 초과**하면 즉시 게임 종료.
- 머지 물리 에너지로 과일이 튕겨 나가 예상치 못한 게임오버가 발생할 수 있다.
- 게임오버 후 **즉시 재시작** 가능. 직전 최고 점수가 함께 표시된다.

## 3. 과일 단계표

| 단계 | 과일 이름 | 상대 크기 | 머지 점수 (Switch) | 낙하 가능 |
|:----:|-----------|:---------:|:-----------------:|:---------:|
| 1 | 🍒 체리 Cherry | ● | 1 pt | ✅ |
| 2 | 🍓 딸기 Strawberry | ●● | 3 pt | ✅ |
| 3 | 🍇 포도 Grapes | ●●● | 6 pt | ✅ |
| 4 | 🍊 데코폰 Dekopon | ●●●● | 10 pt | ✅ |
| 5 | 🍅 감 Persimmon | ●●●●● | 15 pt | ✅ |
| 6 | 🍎 사과 Apple | ●●●●●● | 21 pt | ❌ |
| 7 | 🍐 배 Pear | ●●●●●●● | 28 pt | ❌ |
| 8 | 🍑 복숭아 Peach | ●●●●●●●● | 36 pt | ❌ |
| 9 | 🍍 파인애플 Pineapple | ●●●●●●●●● | 45 pt | ❌ |
| 10 | 🍈 멜론 Melon | ●●●●●●●●●● | 55 pt | ❌ |
| 11 | 🍉 수박 Watermelon | ●●●●●●●●●●● | 66 pt + 소멸 | ❌ |

> **크기 비율** — 각 단계마다 직경 약 1.15~1.3배 증가. 수박 직경 ≈ 체리의 약 5~6배.  
> **낙하 제한** — 사과(6단계) 이상은 머지로만 생성 가능.  
> **수박 합체** — 수박 2개 머지 시 두 과일 모두 소멸하며 66pt 획득. 게임 최종 목표.

## 4. 점수 · 승패 규칙

### 점수 획득

- 머지 1회마다 **해당 단계의 포인트값** 즉시 획득.
- 연쇄 머지 시 **각 단계별 점수가 누적** 합산된다.
- 단일 낙하로 여러 번 연쇄할수록 점수가 기하급수적으로 증가.

### 게임 종료 조건

- 과일이 박스 상단 **게임오버 기준선을 초과**하면 즉시 종료.
- 별도의 클리어 조건 없음. **최고 점수 갱신**이 목표.

### 목표 & 도전

| 구분 | 기준 |
|------|------|
| 공식 목표 | 하이스코어 갱신 |
| 커뮤니티 도전 | 3,000점 달성 (비공식 기준) |
| 궁극 목표 | 수박 2개 합체 완성 (Box Clearing) |

### 리더보드

- **일간 / 월간 / 전체** 3가지 구분으로 타 플레이어와 점수 비교 가능.
- 점수는 게임오버 즉시 기록.
- 2024년 2월 DLC로 **로컬 2인 대전 모드** 추가.

## 5. 화면 · UI 구성

### 전체 레이아웃

```
┌─────────────────────────────────────┐
│  [현재 점수]     [최고 점수]          │  ← 상단 HUD
│                                     │
│         ☁ Poppy (투하 캐릭터)        │  ← 투하 조작 영역
│              🍊 (현재 과일)          │
│  ─────────────────────────────────  │  ← 게임오버 기준선 (빨간 선)
│  │                               │  │
│  │                               │  │
│  │         ( 과일 박스 )          │  │  ← 메인 게임 영역
│  │                               │  │
│  │  🍉  🍑  🍊  🍈  🍒  🍊  🍎  │  │
│  └───────────────────────────────┘  │
│                                     │
│  [다음 과일 미리보기]                 │  ← 하단 또는 사이드 UI
└─────────────────────────────────────┘
```

### UI 요소 상세

| 위치 | 표시 정보 | 비고 |
|------|-----------|------|
| 상단 중앙 | 현재 점수 (대형) | 실시간 업데이트 |
| 상단 우측 | 역대 최고 점수 | 세션 내 갱신 반영 |
| 박스 상단 | 게임오버 기준선 | 빨간 수평선 |
| 기준선 위 | Poppy 캐릭터 + 현재 과일 | X축 이동으로 위치 결정 |
| 사이드 / 하단 | 다음 과일 미리보기 1개 | 전략적 판단 보조 |
| 게임오버 팝업 | 최종 점수 + 재시작 버튼 | 랭킹 확인 링크 포함 |

### 조작 방법

- **PC**: 마우스 좌우 이동 → 클릭으로 낙하
- **모바일**: 터치 드래그로 위치 결정 → 손가락 떼면 낙하
- **Switch**: 조이스틱 좌우 → A 버튼으로 낙하

## 6. 톤 & 분위기

### 색감 팔레트

| 역할 | 색상 | 설명 |
|------|------|------|
| 배경 | `#FFF9F0` 크림 화이트 | 따뜻하고 포근한 느낌 |
| 박스 내부 | `#E8F5E9` 연한 그린 | 자연·과일 연상 |
| UI 강조 | `#FFCC80` 소프트 오렌지 | 버튼, 점수 텍스트 |
| 기준선 | `#EF5350` 코랄 레드 | 위험 경고, 눈에 잘 띔 |
| 과일 색상 | 각 과일 고유 파스텔 계열 | 원색보다 낮은 채도 |

### 아트 방향

- 과일 하나하나에 **귀여운 표정(눈·입)** 삽입.
- **2D 플랫 일러스트** 스타일. 그라디언트 최소화.
- 원색보다 **따뜻하고 채도를 낮춘 파스텔** 계열 사용.
- 머지 시 **반짝임 파티클 이펙트** 연출.
- Aladdin X 공식 언급: *"폭넓은 연령층에 어필하는 귀엽고 친근한 아트"*

### BGM · SFX

| 상황 | 사운드 방향 |
|------|------------|
| 메인 BGM | 잔잔하고 귀여운 J-팝 계열 루프 |
| 과일 낙하 | 통통하고 가벼운 효과음 |
| 머지 성공 | 팝(pop) · 기포 터지는 느낌의 사운드 |
| 연쇄 머지 | 효과음 피치 상승, 기쁨 연출 |
| 게임오버 | 코믹하고 과장된 실패음 |
| 수박 달성 | 특별 팡파레 + 파티클 연출 |

### 분위기 키워드

`릴렉싱` `아기자기` `전략적 긴장감` `중독성 (One more try)` `스트리머 친화적`

> **심리적 훅**: 수박 완성 직전 실패하는 Near-miss 경험 + 귀여운 비주얼 + 예측 불가한 물리 → 반복 플레이를 유도하는 강력한 중독 루프 형성.

## 부록 · 구현 참고 메모

### 기술 스택 참고 (자유 구현 시)

- **물리 엔진**: Matter.js (웹), Box2D (Unity/C++) 등 원형 충돌 지원 엔진 권장.
- **핵심 구현 포인트**:
  - Circle Collider + 리지드바디 중력 처리
  - 동일 과일 접촉 감지 → 머지 트리거
  - 연쇄 머지 큐(Queue) 관리 (동시 다발 머지 처리)
  - 게임오버 라인 초과 감지 (일정 시간 후 판정, 즉각 판정 시 억울한 오버 방지)

### 밸런스 포인트

- 낙하 과일 랜덤 범위를 1~5단계로 제한해 **진입 장벽 완화**.
- 수박 크기를 과도하게 크게 설정하면 **후반 박스 포화** 가속 → 적절한 크기 비율 조정 필요.
- 머지 에너지(반발력)가 너무 크면 **예측 불가 게임오버 빈발** → 플레이어 스트레스 증가.
